    Stenopos Cheatsheet¶

    A single-page reference for the Stenopos language and CLI. For deeper explanations see the Language Guide.

    :material-file-download: Download the printable PDF cheatsheet   View the printable HTML

    A color-coded, multi-column layout that prints cleanly to two Letter/A4 pages.

    CLI commands¶

    Command What it does
    stenopos build <file> Compile a .sten file to a native binary
    stenopos run <file> Compile and run in one step
    stenopos check <file> Type-check only, no binary
    stenopos fmt [--check] <files> Format in place (--check reports, exits 1)
    stenopos lint <files> Report style/correctness lints
    stenopos doc [-o out.md] <file> Generate a Markdown API reference
    stenopos test <file> Run the file's @test functions
    stenopos new <name> Scaffold a new project
    stenopos emit-ir <file> Print Stenopos IR (debugging)
    stenopos emit-llvm <file> Emit LLVM IR (.ll)
    stenopos dump-tokens <file> Print the lexer token stream (debugging)
    stenopos dump-ast <file> Print the parsed AST tree (debugging)
    stenopos explain <code> Explain an error code (e.g. explain E0300)
    stenopos stat [path] Count source lines by language
    stenopos clean Remove build artifacts
    stenopos version Print version
    stenopos help Print help

    Options¶

    Option Effect
    -o <output> Output binary path
    --release Build the release profile (alias for --profile release)
    --profile <name> Build a stenopos.toml profile (default: draft)
    --target <arch> Cross-compile (build only) — see Cross-compilation
    --verify-ir Run the structural IR verifier before codegen
    --verbose Print timing information
    --version Print version
    --help Print help 
    stenopos run hello.sten
stenopos build -o myapp --release main.sten
stenopos build --target aarch64 -o app-arm64 main.sten   # cross-compile

    Build profiles (stenopos.toml). stenopos build uses the draft profile (fast, unoptimized, symbols kept — best for debugging); stenopos build --release uses release (optimized, stripped, and anonymized + RE-hardened: no build-id, hidden symbols, dead code removed, and the stenopos/STENOPOS_ strings dropped so the binary looks like a generic C program). Set the default and customize in the manifest:

    [build]
profile = "draft"        # profile used when you don't pass --profile

[profile.draft]
opt-level = "0"
strip = false

[profile.release]
opt-level = "2"
strip = true

    Types¶

    Keyword Meaning
    int32 int64 Signed integers (fixed width)
    uint32 uint64 Unsigned integers
    float32 float64 IEEE 754 floats
    bool true / false
    str UTF-8 string (owned, length-prefixed)
    T[N] Fixed-size array
    T[] Slice (borrowed view)
    List[T] Growable list
    HashMap[str, V] String-keyed hash map
    T? Nullable
    ptr[T] Raw pointer (unsafe) 
    int32 x = 42
float64 pi = 3.14159
str name = "Stenopos"
bool active = true
int32 flags = zeroed()      // zero value (numeric/bool), type from context
auto n = 42                 // inferred type

    Mutable by default — use const for immutability. No let / mut.

    const int32 MAX = 100

    Functions¶

    func add(int32 a, int32 b) -> int32 {
    return a + b
}

func greet(str name) -> void {       // -> void is required
    println("Hello, {name}!")
}

func identity[T](T val) -> T {       // generics use [T], not <T>
    return val
}

    String interpolation: "total = {a + b}". Booleans interpolate as true/false.

    Return values are must-use by default — a bare compute() that drops a non-void result is an error. Use it, assign it, discard compute() to drop it deliberately, or mark the function @ignore_discard.

    Operators¶

    Group Operators
    Arithmetic + - * / % (overflow traps, never wraps)
    Comparison == != < <= > >=
    Logical && \|\| ! (no and/or/not)
    Bitwise & \| ^ ~ << >>
    Assignment = += -= *= /= %= &= \|= ^= <<= >>=
    Nullable ?. (safe access) · ?? (default) · !! (assert non-null)
    Wrapping wrapping_add · wrapping_sub · wrapping_mul (opt into modular arithmetic)

    Control flow¶

    if (x > 0) {
    // ...
} else if (x == 0) {
    // ...
} else {
    // ...
}

for (i in 0..10) { }        // inclusive range
for (i in 0..<10) { }       // exclusive range
for (item in list) { }
for (i, item in list) { }

while (cond) { }

match (color) {
    case Color.Red: handle_red()
    case Color.Blue: handle_blue()
    case _: handle_other()
}

    One for loop covers all iteration — no foreach. Parentheses and braces are required. Newline terminates a statement (no semicolons).

    Line breaks¶

    // Newline ends a statement — one per line, no semicolons.
int32 x = 42

// A line ending on an operator (that needs a right side) continues — Go's rule:
int32 y = 1 +
          2

// ...and newlines inside ( ) / [ ] are ignored (no trailing comma):
int32 t = add(a,
              b)

    Continuation happens after a dangling operator (+, &&, =, a trailing ., ->, …) or inside brackets. There is no \ continuation. See Statements & Line Breaks.

    Collections¶

    // List[T]
List[int32] xs = list_new()
xs.push(10)
int32 v = xs.get(0)         // bounds-checked
int32 first = xs.first()
int32 last = xs.last()
int32 top = xs.pop()        // remove + return last
xs.sort()                   // ascending; numeric + str elements
xs.reverse()
bool has = xs.contains(10)
int64 at = xs.index_of(10)  // first match, or -1
bool empty = xs.is_empty()
int64 n = xs.len()
xs.clear()                  // empty it, keep capacity

// HashMap[str, V]
HashMap[str, int32] ages = map_new()
ages.insert("ada", 36)
int32 a = ages.get("ada")
bool known = ages.contains("ada")

    Indexing is bounds-checked and aborts on out-of-range — there is no negative indexing; use first() / last() for the ends.

    Structs, classes, enums¶

    struct Point {              // private by default; pub / protected to expose
    float64 x
    float64 y
    pub func norm() -> float64 { return this.x * this.x + this.y * this.y }
}

class Dog : Animal {        // inheritance; `parent`, not `base`
    override func speak() -> void {
        parent.speak()
        println("Woof!")
    }
}

enum Color : int32 {        // backing type required
    Red = 0
    Green = 1
    Blue = 2
}
Point p = Point { x: 1.0, y: 2.0 }

    clone() is a deep copy — modifying a clone never touches the original.

    Error handling¶

    try {
    File f = open("data.txt")
} catch (IOError e) {
    log(e.message)
} finally {
    cleanup()
}

defer close(resource)       // scope cleanup (not error propagation)
throw("something failed")

    try/catch/finally only — there is no ? operator.

    Casting & conversions¶

    float64 f = cast[float64](x)        // safe cast
int32 n = f.to_int32()              // conversion method
const_cast[T](v)                    // drop const
unsafe_cast[T](v)                   // reinterpret (unsafe)
int64 sz = sizeof(Point)

    Nullable types¶

    str? maybe = null
if (maybe != null) {
    println(maybe.len())            // compiler narrows the type
}
int32 len = maybe?.len() ?? 0       // safe access + default
str name = maybe!!                  // assert non-null (aborts if null)

    Concurrency¶

    Seven keywords: spawn chan atomic mutex rwlock spinlock semaphore.

    spawn worker()                      // green thread (Hemerodrome)
chan[int32] ch = chan()
atomic[int64] counter = atomic(0)
counter.fetch_add(1)

mutex[int32] m = mutex(0)
with (m.guard()) {                  // scoped lock, auto-unlocks
    // ...
}

    Memory (NOVA)¶

    Automatic, leak-free memory with no garbage collector. Every value has an owner; heap buffers are freed at scope exit. States used in diagnostics: Declared, Owned, Moved, Borrowed, Locked, Freed.

    unsafe {
    ptr[int32] p = &x
    int32 val = *p
}

    Annotations¶

    Annotation Purpose
    @ignore_discard Callers may drop this function's return value
    @no_return Function never returns
    @packed / @aligned(N) Struct layout control
    @inline / @cold / @hot Optimization hints
    @section("name") Place symbol in a linker section
    @deprecated("msg") Emit a deprecation warning
    @sensitive Encrypt value in the binary
    @tainted / @sanitizer / @sink Taint tracking
    @test Mark a test function
    @repr("C") C-compatible layout
