    The names¶

    Every Stenopos product is named from the world of ancient Sparta and Greece. This page explains what each name means, how to say it, and why it fits.

    Ἀσφάλεια περὶ πλείστου (aspháleia perì pleístou): "Security above all."

    The platform: Stenopos¶
    Greek Στενωπός (stenōpós)
    Say it STEN-oh-pos
    Meaning "The narrow pass"

    In 480 BC, King Leonidas and 300 Spartans held the pass of Thermopylae against the vast army of Persia. They didn't win by being more numerous. They won by choosing the narrow pass: the enemy could only come through one small opening, and that opening was defended.

    That is the Stenopos security design in one image: - Minimize the attack surface. Everything must come through a few narrow, capability-checked gates. - A small, verified core (the nucleus) holds against everything else. - Nothing gets through by default. No root, no ambient authority.

    "Stenopos" names the whole platform: the operating system (Stenopos OS), the programming language and compiler (Stenopos), and the family of products below.

    The mark¶

    The platform's symbol is a golden Spartan (Corinthian) helmet with a red crest, inside a bronze ring. The helmet stands for the hoplite who holds the line: protection first, which is what the platform is built around.

    The motto¶

    Ἀσφάλεια περὶ πλείστου (aspháleia perì pleístou): "Security above all." It is the one motto of the whole platform, and the rule every design decision is measured against.

    Syntagma, tagma and stenopos¶

    Three names, one split (the same as Rust's toolchain, cargo and rustc):

    Name What it is You use it to
    Syntagma The toolchain as a whole: compiler, standard library, tagma, language server. Also the repository and its releases Install and update the toolchain
    tagma The build tool and package manager inside Syntagma tagma new, build, run, test, add, publish
    stenopos The compiler, which tagma runs for you Compile one file directly, or embed the compiler in other tools

    Most people only ever type tagma. The language itself is called Stenopos, the same as the platform, and its files are .sten.

    Plain names¶

    Everyday utilities use plain names, so nobody has to learn a word to find them: Files, Settings, Updates, Passwords, Backup, Terminal. Generic names like these can't be trademarked, and they never conflict.

    Commands¶

    Command Product
    tagma Build tool: tagma new, tagma build, tagma run, tagma test, tagma add, tagma publish
    pano OS package manager: pano install, pano update, pano remove
    hop Hoplite shell
    sten System management: sten info, sten caps, sten logs, sten update, sten env

    File types¶

    File Extension Notes
    Source code .sten Matches the sten command
    Project manifest Tagma.toml Like Rust's Cargo.toml
    OS package .pano Installed by Panoplia
    Compiled programs and libraries Platform standard No extension for executables on Unix-like systems (.exe on Windows); .o, .a, .so / .dylib / .dll for objects and libraries

    Language terms¶

    Names the Stenopos language uses for its own concepts:

    Concept Term Greek Meaning
    Green thread: the lightweight unit of work spawn starts Hemerodrome (short form drome) Ἡμεροδρόμος A day-runner, the messengers who carried news between Greek cities
    OS worker thread that runs Hemerodromes Dromeus (plural dromeis) Δρομεύς A runner

    "Dromeus" and the network stack's "Dromos" share a root (running, the course run); they name different things. The language term replaces the earlier "Flight".
