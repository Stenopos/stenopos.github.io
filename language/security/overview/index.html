    Security Overview¶

    Stenopos makes security properties part of the type system: the compiler rejects the program, rather than a runtime check catching it later.

    What the compiler enforces today¶

    Dimension What it does Example
    Memory safety (NOVA) Automatic, leak-free memory; no use-after-free or double free; bounds-checked indexing; checked integer overflow Memory Safety
    Null safety Only a T? can be null, and it must be checked before use Nullable types
    Taint tracking Untrusted data can't reach a @sink until a @sanitizer has cleaned it Taint Tracking
    Capabilities A function that touches files, processes or the network must declare @cap(...), and so must everything that calls it below
    Effects A @pure function can't do I/O or call anything whose effects are unknown Effect System
    Constant time A secret[T] value can't steer a branch or a division below
    Contracts @requires / @ensures are checked on every call Contracts
    Sensitive data @sensitive values are wiped when freed below

    Capabilities¶

    @cap(File)
func save(str text) -> void {
    discard write_file("/tmp/notes.txt", text)
}

@cap(File)
func main() -> int32 {
    save("hello")
    println(read_file("/tmp/notes.txt"))
    return 0
}

    Remove @cap(File) from main and the program doesn't compile: main calls save, which needs the File capability. The resources are File, Process, Network, Memory and System. A dependency can't quietly start using the network, because its callers would have to grant it.

    Constant-time secrets¶

    func main() -> int32 {
    secret[int32] key = secret(42)
    secret[int32] mixed = wrapping_add(key, secret(8))
    // if (key == 42) { ... }   // error: a secret value may not drive a branch
    // key + 8                  // error: a checked `+` would branch on its overflow
    return 0
}

    Arithmetic on secrets is modular: use wrapping_add, wrapping_sub and wrapping_mul. A checked +, - or * branches on its overflow, and with a secret operand that branch would leak it. Dividing by a secret, indexing with one and shifting by one are errors for the same reason.

    Sensitive data¶

    func main() -> int32 {
    @sensitive str password = "hunter2"
    println(password)
    return 0
}
// the buffer holding the password is wiped before it is freed

    Coming¶

    • Constant-time code generation checked in the compiler's output (today the type rules hold; the generated machine code isn't checked yet).
    • Contracts proved at compile time, not only checked at run time.
    • A misspelled annotation (@sanitiser) is currently ignored; it will be an error.
